Q. int (*t)[10]
1. What is t?
   → Pointer to an array of 10 integers
   → Type: int (*)[10]

2. What is *t?
   → Array of 10 integers
   → Type: int [10]

3. What is (*t)[1]?
   → 2nd element of the first array
   → Type: int

4. What is *t[5]?
   → First element of the 6th array
   → Equivalent to *(t[5]) = t[5][0]
   → Type: int

5. What is *(t+1)?
   → 2nd array of 10 integers
   → Type: int [10]

6. What is t[5]?
   → 6th array of 10 integers
   → Equivalent to *(t+5)
   → Type: int [10]

7. What is *(t[1]+3)?
   → 4th element of the 2nd array
   → Equivalent to t[1][3]
   → Type: int

8. What is t[1][2]?
   → 3rd element of the 2nd array
   → Equivalent to *(*(t+1)+2)
   → Type: int

9. What is **(t+1)?
   → 1st element of the 2nd array
   → Equivalent to t[1][0]
   → Type: int



Q. int t[10][20];
1. What is t?
   → 2D array of 10 rows and 20 columns
   → Type: int [10][20]

2. What is *t?
   → First row (array of 20 integers)
   → Type: int [20]

3. What is (*t)[1]?
   → 2nd element of the first row
   → Equivalent to t[0][1]
   → Type: int

4. What is *t[5]?
   → First element of the 6th row
   → Equivalent to t[5][0]
   → Type: int

5. What is *(t+1)?
   → Second row (array of 20 integers)
   → Equivalent to t[1]
   → Type: int [20]

6. What is t[5]?
   → 6th row (array of 20 integers)
   → Type: int [20]

7. What is *(t[1]+3)?
   → 4th element of the 2nd row
   → Equivalent to t[1][3]
   → Type: int

8. What is t[1][2]?
   → 3rd element of the 2nd row
   → Type: int

9. What is **(t+1)?
   → First element of the 2nd row
   → Equivalent to t[1][0]
   → Type: int
